# 状态记录说明

## 用途

避免用户每次对话都要从头讲一遍已经诊断清楚的处境。`chujingjie` 主入口在每个维度诊断结束后，把结论追加写入本地记录，下次对话开始时先读取最近的记录。

## 存放位置与格式

`~/.chujingjie/records/<日期>.md`，每次追加一段：

```
## <维度名> — <时间戳>
结论：<一两句话>
状态：已解决 / 仍有卡点
```

## 依赖与限制（必须先确认，不要假设）

这套机制依赖运行环境具备**本地文件读写能力**：

- **Claude Code / 其他有文件系统访问权限的 agent 环境**：可以直接落地，按上面的路径读写。
- **纯对话式智能体平台（比如豆包这类未确认是否支持持久化存储的平台）**：需要先确认该平台的智能体后台是否提供"记忆/知识库/变量存储"之类的持久化能力。如果不支持，不要在 SKILL.md 里写"我会记住"这类承诺——没有对应能力时假装记住，比如实回答"这是第一次聊"更容易造成用户困惑。
- 确认某个平台不支持持久化前，`chujingjie/SKILL.md` 里的状态记录部分应保持"仅在环境支持时执行"的措辞，不要默认开启。
